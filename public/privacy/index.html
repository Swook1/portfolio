Privacy Policy

Vera Assistant · Effective 25 September 2026

Summary: Vera Assistant is a private, personal WhatsApp assistant used only by its operator. It does not serve the public, does not sell data, and ignores messages from anyone who is not on its allowlist.

Who operates this service

Vera Assistant ("the bot") is operated by Rayyan Zafier Leksono ("I", "me") as a personal project. It uses the WhatsApp Business Platform (Cloud API) provided by Meta to send and receive messages.

What data is processed

  • WhatsApp messages sent to the bot by allowlisted phone numbers: the sender's phone number, message content and timestamps.
  • Reminders created through the bot: reminder text, time and repeat schedule.
  • Transaction records derived from the operator's own bank notification emails: date, transaction type, merchant or recipient name, and amount. Account numbers are not stored.
  • Messages from numbers that are not allowlisted are ignored. Their content is not stored or processed; only the message ID is kept briefly to prevent duplicate processing, and the sender's number may appear in server logs.

How the data is used

  • To reply to messages, send reminders, and produce spending summaries for the operator.
  • Message content and relevant summaries are sent to a third-party AI model provider to generate replies. Only what is needed to answer a message is sent.
  • Data is not used for advertising, profiling, or any purpose unrelated to the bot's function.

Sharing

Data is not sold or shared, except with the service providers needed to run the bot: Meta (WhatsApp message delivery), the AI model provider (reply generation), and the server hosting provider.

Storage and security

Data is stored in a database on a private server. Access is limited to the operator, connections use HTTPS, and every incoming webhook request is verified with Meta's signature before it is processed.

Retention

Chat history and reminders are kept until they are deleted. Chat history can be cleared at any time by sending /reset to the bot. Transaction records are kept until the operator deletes them.

Data deletion

To have your data deleted, email rayyanzafier@gmail.com with the phone number you used. All stored messages, reminders and related records for that number will be deleted within 30 days, and you will receive a confirmation by email.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
